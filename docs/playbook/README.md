# Introduction

The launch of **Azure Extended Zones** represents a significant opportunity for organisations that require **localised data processing and storage** closer to where workloads and users reside. By enabling data to be stored and processed within the same geographic location, organisations can meet **data residency and compliance requirements**, reduce **application latency**, and support **sustainability and operational efficiency goals**.

This document provides guidance specific to the **Azure xtended Zone**, serving as an initial reference for organisations planning to deploy workloads using **Azure Extended Zones**.

The document focuses on three key areas:

- **Design considerations for Azure Extended Zones**
- **Use cases for Azure Extended Zones**

# Intended Audience

This technical document is intended for **solution architects**, **cloud engineers**, and other **technical stakeholders** responsible for designing, deploying, or operating solutions that leverage **Azure Extended Zones**.
